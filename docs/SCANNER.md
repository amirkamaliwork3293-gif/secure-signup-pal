# اسکنر بارکد/QR

اسکنر از صفر بازنویسی شده است. هدف: رفتار مثل یک دستگاه بارکدخوان واقعی — سریع،
دقیق، فقط آنچه داخل کادر است، و هر کالا فقط یک بار.

## ۱. قرارداد عمومی (بدون تغییر)

```tsx
<Scanner onDetected={(code: string, format?: string) => void} paused={boolean} />
```

`src/components/Scanner.tsx` فقط re-export است؛ `src/routes/scan.tsx` دست نخورده.

اسکنر **هیچ عارضهٔ جانبی روی داده ندارد**: نه دیتابیس، نه Supabase، نه فاکتور،
نه موجودی، نه کش آفلاین. تنها خروجی‌اش صدا زدن `onDetected` با یک رشته است.
کد خروجی همان قبلی است (`normalizeScannedCode`) و تطبیق با محصول همچنان در
`src/lib/barcode-match.ts` انجام می‌شود که **تغییر نکرده**.

## ۲. معماری

```
هر فریم تازهٔ دوربین (requestVideoFrameCallback)
   │
   ├─► BarcodeDetector بومی (ML Kit اندروید)  ← کل فریم، مستقیم از پایپ‌لاین دوربین
   └─► zxing-wasm در Worker                   ← یک برش از چرخهٔ پاس‌ها
          │
          ▼
   ناحیهٔ هدف (مرکز بارکد داخل کادر؟)
          │
          ▼
   Consensus: دقت + ضدتکرار + یک کالا در هر لحظه
          │
          ▼
   بیپ + لرزش + کادر سبز  ──►  onDetected(code)
```

هر موتور حداکثر یک کار در پرواز دارد؛ فریم‌ها صف نمی‌شوند. موتورها هم‌زمان با
باز شدن دوربین گرم می‌شوند.

### چرخهٔ پاس‌ها (`geometry.ts`)

| پاس     | ناحیه                      | حالت دیکود    | برای                           |
| ------- | -------------------------- | ------------- | ------------------------------ |
| focus   | خودِ کادر، ۱:۱             | سریع، سخت‌گیر | بیشتر بارکدها — در **یک فریم** |
| soft    | خودِ کادر، ۱:۱             | عمیق، نرم     | بارکد تار (تأیید دوم لازم)     |
| wide    | کل نمای دیده‌شده، کوچک‌شده | سریع، سخت‌گیر | بارکد/QR بزرگ و نزدیک          |
| micro   | مرکز کادر، ۲× یا ۳×        | عمیق، نرم     | بارکد ریز یا دور               |
| inverse | خودِ کادر، رنگ معکوس       | سریع، سخت‌گیر | لیبل روشن روی زمینهٔ تیره      |

چرخه: `focus, soft, wide, soft, focus, micro, soft, inverse`.

یافته‌های اندازه‌گیری‌شده (در `scripts/test-scanner.ts` تکرارپذیرند):

- **بزرگ‌نمایی فقط با ضریب صحیح.** ضریب کسری (۱.۰۶× یا ۱.۵×) میله‌های بارکد با
  مدول ۱ پیکسل را ناهمسان می‌کند و دیگر خوانده نمی‌شود؛ ۱× و ۲× خوانده می‌شود.
- **`tryHarder` حدود ۱۰ برابر کندتر است.** پاس‌های سریع بدون آن؛ پاس‌های عمیق با
  آن ولی بدون چرخش.
- **`minLineCount`:** با ۲، بارکد تمیز در یک فریم پذیرفته می‌شود ولی بارکد تار
  هرگز؛ با ۱، تار هم خوانده می‌شود ولی هر خوانش تأیید دوم می‌خواهد. هر دو در چرخه‌اند.
- **zxing گزینهٔ `tryInvert` را برای بارکد خطی اعمال نمی‌کند**؛ برای همین پاس
  جداگانهٔ inverse.

### دروازهٔ پذیرش (`consensus.ts`)

- فرمت قوی (EAN/UPC با رقم کنترلی، CODE-128، CODE-93، QR، DataMatrix، PDF417،
  Aztec) با یک خوانش سخت‌گیر پذیرفته می‌شود.
- فرمت ضعیف (CODE-39، ITF، Codabar) یا خوانش تک‌خطی، دو خوانش یکسان در ۱.۲ ثانیه
  لازم دارد (از هر موتور یا پاس).
- رقم کنترلی EAN/UPC دوباره بررسی می‌شود؛ ITF باید زوج‌رقمی باشد.
- **ضدتکرار:** بارکدی که جلوی دوربین مانده فقط یک بار ثبت می‌شود. برای ثبت
  دوبارهٔ همان کالا، بارکد باید ۰.۶۵ ثانیه از دید خارج شود.
- **یک کالا در هر لحظه:** تا وقتی بارکد پذیرفته‌شده هنوز دیده می‌شود، بارکد دیگری
  ثبت نمی‌شود. دو کالای کنار هم دیگر به‌طور متناوب و بی‌پایان به فاکتور اضافه
  نمی‌شوند.
- **ناحیهٔ هدف:** بارکدی که مرکزش بیرون از کادر است نادیده گرفته می‌شود.

### دوربین (`camera.ts`، `lens.ts`)

1. لنزی که قبلاً روی همین دستگاه **واقعاً بارکد خوانده** مستقیم باز می‌شود.
2. وگرنه `facingMode: environment`؛ سپس اگر برچسب لنزها نشان دهد لنز بهتری هست
   (فوق‌عریض/تله/ماکرو تنزل؛ «camera2 0» و «Back Camera» ترجیح)، جابه‌جایی.
3. فوکوس پیوسته، زوم شروع ۱.۵× (فقط اگر دوربین ۲× یا بیشتر دارد).
4. وضوح ایده‌آل 1920×1080.

با پنهان شدن صفحه دوربین آزاد و با برگشت دوباره باز می‌شود. اگر سیستم دوربین را
قطع کند، دو بار خودکار تلاش می‌شود و بعد پیام «تلاش دوباره».

### گرفتن فریم (`frame-grabber.ts`)

`drawImage(video)` روی canvas. روی بعضی سامسونگ‌ها این کپی سیاه است (پیش‌نمایش
زنده می‌ماند)؛ بعد از ۳ فریم یکنواخت، منبع به `ImageCapture.grabFrame()` تغییر
می‌کند. موتور بومی به این کپی وابسته نیست.

## ۳. امکانات

- چراغ قوه، دکمه‌های زوم (۱× ۱.۵× ۲× ۳× …)، تغییر لنز، فوکوس با لمس.
- بیپ و لرزش (قابل خاموش کردن)، پرش سبز، کادر ردیابی دور بارکد، نمایش کد خوانده‌شده.
- **اسکن از عکس** (گالری یا دوربین سیستم) — وقتی دوربین زنده در دسترس نیست.
- **بارکدخوان سخت‌افزاری** USB/بلوتوث (`keyboard-wedge.ts`): تایپ بسیار سریع +
  Enter تشخیص داده می‌شود. وقتی فوکوس داخل فیلد جست‌وجوست کاری نمی‌کند. با کیبورد
  فارسی هم کار می‌کند (کاراکتر از کلید فیزیکی بازسازی می‌شود).

## ۴. فرمت‌ها

EAN-13، EAN-8، UPC-A، UPC-E، CODE-128 (کد تولیدی اپ)، CODE-93، CODE-39، ITF،
Codabar، DataBar، QR، DataMatrix، PDF417، Aztec.

zxing برای UPC-A مقدار ۱۳رقمی با صفر پیشوند برمی‌گرداند؛ `barcode-match.ts`
این حالت را از قبل پوشش می‌دهد.

## ۵. ذخیره‌سازی

اسکنر فقط دو کلید `localStorage` می‌نویسد، هر دو تنظیم دستگاه (`prefs.ts`):

- `kamix_scanner_lens` — شناسهٔ لنزی که روی این دستگاه بارکد خوانده.
- `kamix_scanner_sound` — `"0"` یعنی بیپ خاموش.

هر دسترسی داخل `try/catch` است.

## ۶. فایل‌ها

```
src/features/barcode-scanner/
  index.ts              خروجی عمومی
  Scanner.tsx           فقط UI
  useBarcodeScanner.ts  پل React ↔ ScanEngine
  engine.ts             حلقهٔ فریم، موتورها، کنترل‌ها، dispose واحد
  consensus.ts          دروازهٔ پذیرش (خالص)
  geometry.ts           پاس‌ها، برش، نگاشت object-fit:cover، ناحیهٔ هدف (خالص)
  formats.ts            جدول فرمت‌ها، رقم کنترلی (خالص)
  lens.ts               رتبه‌بندی لنز و زوم (خالص)
  keyboard-wedge.ts     بارکدخوان سخت‌افزاری
  camera.ts             باز/بست استریم، چراغ، زوم، فوکوس
  frame-grabber.ts      برش فریم + تشخیص فریم سیاه
  feedback.ts           بیپ و لرزش
  image-scan.ts         اسکن از عکس (بارگذاری پویا)
  prefs.ts              تنها نقطهٔ ذخیره‌سازی
  engines/
    native.ts           BarcodeDetector بومی، با سقف زمانی و خاموشی خودکار
    zxing-core.ts       دیکود پیکسل (مشترک Worker، ترد اصلی، تست)
    zxing-setup.ts      آدرس wasm از باندل (بدون CDN)
    zxing.worker.ts     Worker دیکود
    zxing-client.ts     Worker با پشتیبان ترد اصلی
    protocol.ts         پیام‌های Worker
```

## ۷. تست

```
npx --yes tsx --tsconfig tsconfig.json scripts/test-scanner.ts
```

منطق خالص + شبیه‌سازی کامل پایپ‌لاین روی فریم ۱۰۸۰p مصنوعی با همان کد پروداکشن:
بارکد بسیار ریز (مدول ۱ پیکسل) تا بسیار بزرگ (بیرون از کادر)، عمودی، تار، معکوس،
خارج از مرکز، همهٔ فرمت‌ها، دو بارکد هم‌زمان و فریم خالی (بدون خوانش کاذب).

## ۸. عیب‌یابی

ریشهٔ اسکنر دو ویژگی دارد که در DevTools دیده می‌شوند:
`data-scanner-zxing` (`worker` / `main` / `none`) و `data-scanner-native` (`on` / `off`).
